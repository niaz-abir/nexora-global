# Nexora Global

Deep-gradient visa consultation website for Nexora Global, Uttara, Dhaka, Bangladesh.

## Stack
Next.js 14 + React + JavaScript only + CSS + Lucide React.

## Run
npm install
npm run dev

## Build
npm run build

## Vercel
Import the project into Vercel. No environment variables are required for the frontend demo.

## Before delivery
Replace the placeholder email and phone in app/page.js with the client's real details. The consultation form currently demonstrates the frontend success state; connect it to the client's preferred email/CRM/backend workflow when available.
